# F0 patch 0.1.1 — Direct PDF import

The previous Import / Rebuild dialog accepted folders only, so individual PDF files could not be selected. The ingestion entry point also rejected file paths.

## Updated behavior

- Import / Rebuild accepts one PDF, UTF-8 TXT or Markdown file, or one folder.
- A selected file is imported by itself; neighboring files are not imported.
- A selected folder is still scanned recursively for supported files.
- PDF citations retain the selected filename and physical page number. Text citations retain line ranges.
- Each successful import rebuilds and replaces the current course index. Select the course-materials folder to use all five lectures together.
- An import with no usable text retains the previous index. Scanned PDFs still require external OCR.

## Validation

- All 21 core tests passed, including three new regressions. Those three tests failed against the previous ingestion implementation before the fix.
- The direct-PDF regression reads a two-page PDF with a Chinese filename, spaces and an uppercase extension, checks both page references, and verifies that a neighboring text file is excluded.
- Plugin compilation, packaging and the Gradle configuration check completed successfully. The existing advisory about limiting compatibility to build 261.* remains.
- Full course audit results are in evidence/course-audit.json; automated test results are in evidence/core-tests.xml.
- Interactive IDEA selection and a live LLM request were not tested for this patch.

## Install

Use Settings > Plugins > gear > Install Plugin from Disk to select plugin/course-ta-0.1.1.zip. Restart IDEA when prompted, open Course TA, click Import / Rebuild and select a PDF directly. Preview retrieval works without an API key.

The existing PDF report and presentation describe the 0.1.0 baseline. This note documents the changes and validation for 0.1.1.
